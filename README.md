# Утилита RTK/RTCM + DeepSeek

Есть **два интерфейса** для получения справки по **геодезии и RTK-поправкам**
и получения ответов от языковой модели DeepSeek API:

- **Веб-версия** (`rtk_web.py`) — веб-страница на встроенном HTTP-сервере Python
  (стандартная библиотека). Открывается в браузере, ответ показывается прямо
  на странице.
- **Консольная версия** (`rtk_console.py`) — диалог в терминале, сохраняет
  HTML-ответ в папку `answer/`.

Пользователь вводит вопрос свободным текстом, утилита проверяет, что вопрос по
теме, запрашивает DeepSeek и показывает/сохраняет ответ в виде таблицы.

## Возможности

- **Свободный ввод вопроса** — пользователь пишет запрос вручную, а не
  выбирает из списка.
- **Проверка темы вопроса** — быстрая проверка по ключевым словам
  (учитываются англ., рус. и транслит-варианты: RTK, RTCM, CMR, ЦМР, РТЦМ, РТК,
  GNSS и т.п.), при недостаточных ключевых словах — проверка через DeepSeek.
- **Подсказки по теме** — если вопрос не по теме, утилита предлагает короткие
  тезисы о видах RTK-поправок и запрашивает повторное введение.
- **Формат ответа на выбор**: короткий (до 10 слов на поправку) или полный.
- **Ответ в виде таблицы из 3 столбцов**:
  - дата появления RTK-поправки;
  - «Описание версии» (текст, при полном ответе выравнивается по ширине);
  - размер поправки в байтах.
- **Сортировка** RTK-поправок по времени появления (от ранней к поздней),
  при равенстве — по размеру (по возрастанию).
- Сохранение красивого HTML-файла в папку `answer/` (консоль) или показ
  результата прямо на веб-странице.

## Требования

- Python 3.7+
- Только стандартная библиотека (`urllib`, `json`, `re`, `os`) —
  **внешние зависимости не нужны**.

## Установка

Склонируйте репозиторий:

```bash
git clone https://github.com/kykich/3108.git
cd 3108
```

## Настройка API-ключа

1. Получите API-ключ на [platform.deepseek.com](https://platform.deepseek.com).
2. Создайте рядом со скриптом файл **`apidpsk.txt`** и вставьте в него ключ
   одной строкой (без лишних пробелов):

```
sk-ваш_ключ_из_deepseek
```

> ⚠️ **Важно:** файл `apidpsk.txt` добавлен в `.gitignore` и не должен
> загружаться на GitHub — это ваш секретный ключ.

## Запуск

### Веб-версия (рекомендуется)

Стартовая страница **`index.html` лежит в корне проекта**. Запуск поднимает
встроенный HTTP-сервер и автоматически открывает страницу в браузере. Если же
открыть `index.html` просто как локальный файл (двойным кликом), встроенный
сценарий страницы автоматически перенаправит вас на порт запущенного сервера
(`http://127.0.0.1:8000`), где обслуживаются интерфейс и `/api/ask`.

```bash
python rtk_web.py
```

Либо на Windows:

```powershell
py rtk_web.py
```

Можно указать порт (и хост). При нестандартном порте страница открывается по
адресу `http://127.0.0.1:<порт>/`:

```bash
python rtk_web.py 9000           # http://127.0.0.1:9000
python rtk_web.py 9000 0.0.0.0   # доступ с других машин
```

После запуска откроется веб-страница с полем для вопроса, выбором формата
ответа и кнопкой «Получить ответ».

### Консольная версия

```bash
python rtk_console.py
```

Пример сценария работы:

```
Ваш вопрос: какие бывают виды RTK-поправок
   [CHECK] Проверяю тему вопроса...

В каком виде выдать ответ?
   1 — короткий
   2 — полный
Ваш выбор (1-2): 2

[REQ] Отправка запроса к DeepSeek...
[OK] Ответ получен.
[SAVED] Ответ сохранён: answer\deepseek_2025-01-01_12-00-00.html
```

└── .gitignore

> Файл `apidpsk.txt` (секретный ключ) и папка `answer/` (результаты консоли)
> добавлены в `.gitignore` и не попадут на GitHub.
